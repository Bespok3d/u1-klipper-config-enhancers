# Attributions - purge-line-back

**Plugin author:** DocKuro, packaged by Bespok3d

Moves the purge line to the back of the bed.

The macro this plugin ships was written by DocKuro and posted in the Snapmaker Discord on
2026-01-15, in the U1 firmware thread "GCODE Macro to move the purge lines to the back of the
plate". It is used here with that origin recorded; Bespok3d packaged it as a Bespok3d plugin so it
installs without the Extended Firmware.

No other third-party code ships in this package.
